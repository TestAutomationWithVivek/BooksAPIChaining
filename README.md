# 📚 Books API - Postman Collection with Newman, Jenkins & Email Integration

This project demonstrates API testing using a chained Postman collection for a **Books API**, automated with **Newman CLI**, integrated with **GitHub**, executed via **Jenkins Freestyle Job**, and set up to send **email notifications** upon build completion.

---

## 🚀 Features

- ✅ Chained API Requests: `POST` → `GET` → `PUT` → `DELETE`
- 🔄 Environment variables used for API chaining
- 🧪 Newman CLI for automated test execution
- 📂 HTML reporting for test results
- ⚙️ Jenkins Freestyle Project for CI integration
- 📧 Email notifications with attached test reports
